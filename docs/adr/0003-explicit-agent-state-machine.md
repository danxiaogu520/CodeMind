# ADR-0003：采用显式 Agent 状态机

- 状态：accepted
- 日期：2026-07-20
- 补充：默认执行引擎由 [ADR-0004](0004-langgraph-workflow-runtime.md) 确定为 LangGraph

## 背景

自由 ReAct 循环实现快，但步骤不可预测，容易超预算、重复调用工具，也难以恢复和评测。

## 决策

以持久化 `RunState` 驱动有限状态机；常见任务使用预置工作流，开放式 Planner 作为回退。所有工具只读、白名单、schema 化，并受步骤/Token/时间预算约束。

## 后果

流程可观察、可测试、可重试，适合作品展示和生产演进；新增任务需要显式定义状态或策略。底层默认使用 LangGraph，但领域状态与工具契约不依赖它。

## 替代方案

- 完全自由 Agent：稳定性和成本不可控；
- 固定单链 RAG：无法完成调用关系和多步分析。
