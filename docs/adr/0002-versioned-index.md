# ADR-0002：采用版本化双索引

- 状态：accepted
- 日期：2026-07-20

## 背景

向量索引和 BM25/元数据无法天然共享单个跨系统事务，增量更新可能使查询读到半成品。

## 决策

每次索引产生不可变 `index_version`。所有记录携带版本过滤条件，全部写入成功后，才在 PostgreSQL 事务中切换仓库的活动版本。

## 后果

读请求获得一致快照，也能回滚和复现实验；代价是短期双份存储和后台回收逻辑。Agent Run 在开始时固定版本。

## 替代方案

- 原地更新：简单但会暴露部分更新；
- 全局维护窗口：影响可用性，不适合持续导入。
