# ADR-0001：采用模块化单体与端口适配器

- 状态：accepted
- 日期：2026-07-20

## 背景

MVP 同时包含解析、索引、检索和 Agent，但团队与流量规模尚不足以证明微服务的运维成本。

## 决策

使用单一 Python 代码库，以领域模块隔离能力；API 和 Worker 作为不同进程部署。外部系统通过 Protocol/端口接入。

## 后果

可以快速完成端到端能力并复用类型；需要通过依赖规则和测试防止模块互相穿透。未来按性能或扩展需求拆分 Worker/检索服务时，端口契约提供边界。

## 替代方案

- 一开始拆微服务：部署和一致性成本过高；
- 所有逻辑放 FastAPI 路由：难以测试和演进。
